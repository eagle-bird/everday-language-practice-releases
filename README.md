# Как установить EverydayEnglish (простая версия)

Понадобится архив вида `EverydayEnglish-0.2.1.zip` (цифры могут отличаться, это номер версии). Скачайте его
со страницы https://github.com/eagle-bird/everday-language-practice-releases/releases/latest, раздел Assets. Сохраните его куда угодно и ничего с ним не делайте, распаковывать не нужно.
Запомните только, где он лежит.

## Шаг 1. Открыть Терминал

Нажмите одновременно клавиши **⌘ (Command) и пробел**. Появится строка поиска. Напечатайте в ней
**Терминал** и нажмите **Enter**. Откроется окно с текстом и мигающим курсором. Это и есть Терминал.

## Шаг 2. Вставить команды

Первая команда зависит от того, где лежит архив.

**Если архив в папке «Загрузки».** Скопируйте строку ниже целиком (выделить, затем ⌘C), щёлкните в окно
Терминала, вставьте (⌘V) и нажмите **Enter**:

```bash
ditto -x -k ~/Downloads/EverydayEnglish*.zip /Applications/
```

Если в «Загрузках» скопилось несколько архивов разных версий, удалите старые, иначе команда распакует все.

**Если архив в другом месте.** Скопируйте и вставьте в Терминал вот это, с пробелом в конце, Enter пока
не нажимайте:

```bash
ditto -x -k 
```

Затем найдите архив в Finder и перетащите его мышкой прямо в окно Терминала. В строке сам собой появится
путь к файлу. После него допечатайте пробел и `/Applications/`, чтобы получилось примерно так:

```
ditto -x -k /Users/anna/Desktop/EverydayEnglish-0.2.1.zip /Applications/
```

Теперь нажмите **Enter**.

**Вторая команда одинаковая для всех.** Скопируйте, вставьте, нажмите **Enter**:

```bash
xattr -dr com.apple.quarantine /Applications/EverydayEnglish.app; chmod +x /Applications/EverydayEnglish.app/Contents/MacOS/EverydayEnglish; open /Applications/EverydayEnglish.app
```

После второй строки приложение откроется само. Терминал можно закрыть.

## Шаг 3. Дальше

Приложение теперь лежит в папке «Программы», как и все остальные. Открывать его можно через Launchpad
или тем же поиском ⌘ + пробел, набрав **EverydayEnglish**.

При первом запуске macOS может спросить разрешения: на доступ к микрофону, на распознавание речи,
на «Универсальный доступ». Нажимайте «Разрешить». Если окно отправит в Системные настройки, включите там
переключатель рядом с EverydayEnglish.

## Если что-то пошло не так

- Терминал пишет **No such file or directory** после первой команды: путь к архиву указан неверно.
  Воспользуйтесь вариантом с перетаскиванием файла в окно Терминала, он не ошибается.
- macOS пишет, что приложение **повреждено** или **не удаётся проверить**: ещё раз выполните вторую строку
  из шага 2.
- Терминал спрашивает **пароль**: введите пароль от вашего Mac. Символы при вводе не отображаются, это
  нормально. Нажмите Enter.

Функции с искусственным интеллектом (проверка текста, подсказки) требуют отдельной программы Codex от
ChatGPT. Если они не работают, попросите того, кто дал вам приложение, помочь её настроить.
